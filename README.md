# Клатч — карточная тактика CT против T для Telegram Mini App

Карточный бой по CS2 в духе Hearthstone: колода, рука, герои-агенты, деньги вместо маны. Каждая сторона выставляет до 6 бойцов, классы оружия контрят друг друга, T могут заложить бомбу. Перед матчем — ножевой раунд, победитель выбирает сторону, дальше одна партия. Против бота — без сервера. Онлайн (рейтинг, дуэли с другом) — через небольшой сервер на Bun из папки `server/`.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # сборка в dist/
npm run simulate   # 1000 игр бот против бота: баланс сторон и агентов
```

`bash scripts/standalone.sh` — однофайловая сборка `dist-standalone.html` (картинки встроены).

## Подключение к Telegram

1. Залейте `dist/` на HTTPS, например `https://cs2assist.ru/clutch/`.
2. В [@BotFather](https://t.me/BotFather): `/newapp` → выберите бота → укажите URL.
3. Опционально `/setmenubutton` — кнопка «Играть» в чате.

## Правила

Раскладка стола (сверху вниз): герой соперника, его карты рубашкой вверх, его бойцы, полоса хода, ваши бойцы, ваша рука, ваш герой — герои у краёв, карты впереди них.

Без рядов: у каждой стороны одна линия **до 6 бойцов**, рука до 7 карт, колода 20 карт.
- **Колода:** арсенал агента ×2 + 2 фирменные карты агента ×2 + основа стороны + случайный добор из пула (партии не повторяются).
- **Добор на выбор:** в начале хода открываются 2 верхние карты — одну берёте, вторая уходит под низ колоды. Стартовая рука 4 карты (у второго игрока 5), предел руки 7.
- **Бай-меню:** выбрать 1 из 3 карт своего агента и стороны (арсенал, фирменные, общие). Первая покупка за ход $1000, вторая $2000, третья $3000 и т. д. — так лишние деньги в поздней игре превращаются в карты.
- **Живучесть:** здоровье бойцов ×1.5 от базовых значений, герой 50 HP («Оборона» — 58), герой CT начинает с 5 брони. Урон гранат увеличен пропорционально.
- **Бонус за отставание (как loss bonus в CS):** если в начале хода здоровье вашего героя меньше, чем у соперника, на 5+, вы получаете +$500 за каждый такой ход подряд, до +$2000. Сравнялись — серия сбрасывается.
- **Эко раунд:** если за ход не сыграно ни одной карты, не открыто бай-меню и не использована сила героя, вместо «Конец хода» горит золотая кнопка «Эко раунд». Со второго хода (пистолетный раунд эко не бывает). Нажатие — выбор: +2 карты в руку сейчас (несыгранные деньги переносятся как обычно) или +$3 к деньгам следующего хода вместо переноса. Числа — `eco`, `ecoCards`, `ecoCash`, `ecoMinTurn`, `ecoKeepsCarry` в `HS`. Бот тоже играет эко, когда ему нечего сыграть. Проверка (`scripts/eco-test.ts`): нарочное эко деньгами на 2-м ходу почти не меняет шансы (T 53%, CT 48%), картами позже — проигрышно; без ограничений (эко на 1-м ходу и сверх переноса) давало до 74% — поэтому правила такие.
- **Деньги на экране — в тысячах, через запятую, с буквой K:** $5,3K = $5300, $0,6K = $600 (как цены на картах).
- **Деньги — мана:** $2000 в первый ход, +$500 каждый ход до $5000 (с 7-го хода доход больше не растёт). До $3000 неистраченных переходят дальше сверх дохода — можно сыграть «эко» и накопить на дорогую карту. Награда за убийство ($300–600) — в следующем ходу.
- **Цены по уровням:** дешёвые пистолеты $1000–1500 слабые, ПП и дробовики $2000–4000, винтовки $3500–6500 и снайперки/пулемёты $5000–7000 заметно сильнее и с особыми свойствами. Весь стол хорошими картами не закупить — приходится выбирать.
- **Кто кого:** ПП достают снайперов за укрытием (+2); дробовики +2 по ПП, пистолетам и укрытиям; снайперки +2 по дробовикам и пулемётам и без ответного урона; винтовки пробивают броню; пулемёты держат линию, но гранаты бьют их на +2. Цифра бонуса видна на цели при выборе атаки.
- **Броня:** режет каждое попадание пистолетов, ПП, дробовиков и гранат (1 урон проходит всегда).
- **Ветераны ★:** убийство даёт бонус по классу (пистолет — Хедшот, ПП — Очередь, дробовик — +2 HP, винтовка — +1 атаки и Шлем, снайперка — +2 атаки, пулемёт — Укрытие).
- **Трофеи:** если вы убили бойца, который ещё не нанёс ни единицы урона, его оружие «с полным магазином» уходит вам в руку и ставится бесплатно. Другого подбора оружия нет.
- **Ослепление:** ослеплённый боец пропускает атаку и не стреляет в ответ.
- **Засады** (до 2, рубашкой вверх): Держит угол, Растяжка, Фейк, Ниндзя-дефьюз, Тиммейт на подхвате, Минное поле (Партизан).
- **Фирменные карты:** SWAT — Щитовик, Склад брони; SEAL — Корректировщик, Дальний выстрел; FBI — Разведданные, Сапёр; SAS — Штурм-группа, Оператор; GIGN — Баллистический щит, Жандарм; Phoenix — Подрывник, Быстрая закладка; Elite — Раш, Штурмовик-ветеран; Balkan — Огненная стена, Пулемётчик; Партизан — Засадник, Минное поле; Наёмник — Контракт, Наёмник-ветеран.
- T ходят первыми. CT: +1 карта и «Дроп».
- **Ножевой раунд** (`src/hs/knife.ts`) решает сторону: оба тайно выбирают «Нож», «Щит» или «Zeus» (Нож бьёт Zeus, Zeus бьёт Щит, Щит бьёт Нож; одинаковые — ничья). У каждого 3 жизни, любая победа в обмене снимает одну. Победитель выбирает T или CT, дальше одна партия. Онлайн проигравший ножи первым вычёркивает карту в вето; на приём 12 с (`KNIFE_SEC`), на выбор стороны 15 с (`SIDE_SEC`).
- **Бомба как в CS.** C4 у T всегда лежит в стартовой руке ($3000, 0/9). Заложить можно только с третьего своего хода. Не обезвредили за 4 хода — победа T; обезвредили (бомба потеряла всё здоровье) — **победа CT**. Пока с обеих сторон от бомбы стоят живые неослеплённые бойцы T, её нельзя бить («под охраной») — сначала надо пробить охрану. За закладку T получают +$600 в следующем ходу. Числа — `bombTimer`, `bombHp`, `plantTurn`, `defuseWins`, `bombGuarded`, `bombGuardMin`, `plantBonus` в `HS` (`src/hs/engine.ts`).
- Код: `src/hs/` (cards, engine, ai, ui). Баланс: `bun scripts/hs-sim.ts 1000 [easy|normal|hard]` (числа `HS` можно подменить: `HS='{"bombTimer":4}' bun scripts/hs-sim.ts 1000`). По 6000 играм: T 49,8%; взрывом заканчивается 49%, разминированием — 50% партий.

## Управление

- Карту можно сыграть как раньше: нажать карту → «На стол» → место в ряду (и цель, если нужна).
- Или сразу перетащить её из руки, пальцем или мышью. Бойца или бомбу — в нужное место своего ряда (золотая метка показывает, куда встанет). Гранату или действие с целью — прямо на цель (она подсвечивается). Действие без цели — на поле. Если у карты есть режим стрельбы, после броска останется выбрать его кнопкой. Если боец при выходе бьёт по цели, её выбирают нажатием. Отпустить карту над рукой — отмена.
- Флешка вспыхивает только над той стороной стола, где взорвалась.

## Механики из CS

- **Позиция на столе.** При выходе бойца выбирается место. Соседство важно: Дробь и Флешка задевают соседей, Жандарм усиливает соседей, а бойцы рядом с Укрытием не видны вражеским снайперам.
- **Энтри.** Первое убийство бойцом в свой ход — +$300 в следующем ходу (у «Раша» +$600 и +1 атаки бойцу).
- **Трейд.** Убийца вашего бойца помечен: ваши бойцы бьют его на 2 сильнее до конца вашего следующего хода.
- **Клатч.** Последний боец против двух и больше бьёт на 2 сильнее.
- **Сейв.** Раз в ход боец, который не стрелял и не вышел в этом ходу, может уйти со стола — карта возвращается в руку.
- **Режимы стрельбы.** Glock (одиночный/бёрст), USP-S и M4A1-S (с глушителем/без), FAMAS (очередь/одиночный), Galil (раш/прицельно), SG 553 и AUG (с прицелом/без) — режим выбирается при розыгрыше.
- **Журнал боя** — кнопка «Журнал» в центре стола: все действия обеих сторон по ходам.

## Выстрелы

Каждое оружие на картах стреляет своим настоящим звуком из CS2: `public/snd/shot/<id карты>.mp3` (варианты `<id>_2.mp3`), список `index.json` собирается вместе с голосом. Источник — `sounds/weapons/<оружие>/` в pak01: обрезано до 1,7 с (снайперки, Deagle, R8, Negev — 2,4 с), моно 44 кГц, выровнена громкость.

- USP-S и M4A1-S в режиме «без глушителя» звучат как в игре без глушителя (`usp_us`, `m4a1s_us`).
- Фирменные бойцы и токены стреляют оружием своего класса: Щитовик SWAT — M4A4, Корректировщик — P2000, Сапёр FBI — MP5-SD, Оператор SAS — M4A1-S, Жандарм — PP-Bizon, Подрывник — Tec-9, Штурмовик Elite — AK-47, Пулемётчик Balkan — Negev, Засадник — MAC-10, Наёмник-ветеран — Galil AR, Наёмник и Тиммейт T — Glock, Тиммейт CT — P2000 (таблица `SHOT_ALIAS` в `src/sound.ts`).
- Атака героя — нож, Zeus — выстрел тейзера, сила SEAL — SCAR-20, сила SAS — M4A1-S.
- Если файла нет, играет прежний синтезированный выстрел.
- Бомба тоже звучит как в игре (`sounds/weapons/c4`): набор кода при закладке (`c4_key`), установка и взвод (`c4_plant`, `c4_arm`), писк таймера (`c4_beep`, на последнем ходу — `c4_beep_fast`), разминирование (`c4_defuse_start`, `c4_defuse`) и взрыв (`c4_boom`, обрезан до 4,5 с). Функции — объект `c4` в `src/sound.ts`.
- Пересобрать из игры: `python3 scripts/cs2-vo-extract.py "<…>/game/csgo"` (голос, выстрелы и бомба).

## Стили агентов (как классы в Hearthstone)

Раш бьёт дальнюю игру, оборона держит раш, дальняя игра ломает оборону. У каждой стороны есть все три стиля. Перед игрой показывается, выгодный ли матчап.

| Стиль | Агенты | Пассивное свойство |
|---|---|---|
| » Раш | SAS, Phoenix, Elite Crew | Бойцы с Рывком +1 атаки и +1 здоровья; энтри-фраг даёт $600 и +1 атаки бойцу |
| ▣ Оборона | SWAT, GIGN, Balkan | Герой 58 HP; вражеский Рывок не срабатывает; бойцы с Укрытием +1 здоровья и +1 брони; гранаты и огонь +1 урона |

Часть колоды (4 карты) добирается под стиль. Симуляция: выгодный матчап выигрывается в 62–67% игр (оборона против раша 67%, раш против дальней 64%, дальняя против обороны 62%).

## Проверка баланса

Последний прогон (6000 партий бот против бота, все 25 пар агентов, все локации): T побеждает 49,8%, бомба взрывается в 49% партий, обезвреживается в 50%, партия длится в среднем 5,7 хода каждого. Агенты — от 45,5% (SWAT, SAS) до 55% (SEAL). Здоровье героя: 50, «Оборона» 58, поправки — SWAT +3, SEAL +3, Наёмник +2. Побед «по герою» почти не осталось: партию решает бомба. Сложность бота: «Новичок» играет с большим шумом и иногда заканчивает ход раньше; «Сложный» смотрит на шаг вперёд и выигрывает у «Обычного» около 64% партий.

`bun scripts/balance.ts <игр на пару> <часть> <частей> [сложность T] [сложность CT] > out.jsonl` — бот против бота, каждая пара агентов T × CT на всех локациях (части — для запуска в несколько процессов). Сводка: `python3 scripts/balance-report.py out*.jsonl` — стороны, агенты, матрица пар, локации и карты, после розыгрыша которых побеждают чаще или реже.

## Онлайн

Сервер — `server/server.ts` (Bun, без зависимостей, SQLite встроен). На нём лежит настоящий стол и работает тот же движок, что и в игре; клиент только присылает действия. Каждому игроку уходит его вид стола: карты в руке и колоде соперника, его засады и открытый выбор скрыты.

- **Рейтинговая игра:** очередь, подбор по рейтингу (окно ±100, растёт с ожиданием), одна игра (Bo1), вето карт как в Premier — игроки по очереди вычёркивают карты (15 с на ход), последняя оставшаяся — карта матча. Голос диктора CS2 озвучивает вето и сторону.
- **Дуэль с другом:** «Создать ссылку» → код из 6 символов и ссылка `t.me/<бот>/<app>?startapp=duel_КОД`; друг открывает ссылку и сразу попадает в дуэль (или вводит код). Без рейтинга.
- **Таймер хода** 30 с (только онлайн; против бота и в обучении его нет) — бомба C4 слева на центральной полосе. Последние 10 с она пищит чаще и растёт; не успели — ход переходит сопернику (открытый добор — берётся первая карта). Замена карт онлайн — 30 с.
- **Переподключение:** пропала связь — у игрока минута, чтобы вернуться (соперник видит «не в сети» и таймер). Не вернулся — техническое поражение и штраф **−35 Elo** (вместо обычного расчёта; сопернику — обычная победа). Бана нет. Число — `LEAVE_PENALTY` в сервере.
- **Друзья и соперники:** в «Рейтинге» — список друзей (в сети / в матче / не в сети) и недавних соперников. Нажатие открывает профиль: уровень, Elo, место, ваши личные встречи, последние матчи, «Добавить в друзья» и «Вызвать на дуэль». Вызов приходит другу всплывающим окном поверх любого экрана («Принять» / «Отклонить», 60 с); в матче вызовы не принимаются. Строки истории тоже открывают профиль соперника.
- **Реванш:** на экране итога онлайн-матча — «Реванш». Когда нажали оба (в течение 2 минут), сразу начинается новая игра без рейтинга, с ножевым раундом.
- **Рейтинг Эло** — 10 уровней как на FACEIT, подробности ниже. Таблица лидеров — топ-50 сезона.
- **Сезоны:** `bun server/server.ts --new-season "Сезон 2"` — рейтинг сжимается к 1000 вдвое, счёт игр сезона обнуляется.
- **Рация вместо чата:** кнопка 📻 рядом с журналом — готовые фразы голосом вашего агента, не чаще раза в 2,5 с.
- **Сдаться** — кнопка вместо «Меню» во время онлайн-игры (нажать дважды).

Запуск:

```bash
BOT_TOKEN=123:ABC STATS_KEY=пароль-аналитики PORT=8790 DB=/var/lib/clutch/online.sqlite bun server/server.ts
```

nginx на домене игры:

```nginx
location /clutch-ws/ {
    proxy_pass http://127.0.0.1:8790/;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_read_timeout 300s;
}
```

В игре: константа `SERVER` в `src/online/client.ts` (например `wss://cs2assist.ru/clutch-ws/ws`) и `BOT_APP` — «имя_бота/короткое_имя_приложения» для ссылок-приглашений. Можно и без пересборки: `<script>window.CLUTCH_SERVER='wss://…/clutch-ws/ws'; window.CLUTCH_BOT_APP='clutch_bot/play'</script>`. Для проверки — `?server=ws://localhost:8790/ws` в адресе.

Вход проверяется по подписи Telegram `initData` (нужен `BOT_TOKEN`). Без токена сервер пускает по случайному имени устройства — только для локальной проверки (`ALLOW_DEV=1`). Прочие настройки: `TURN_SEC`, `MULL_SEC`, `BAN_SEC`, `GRACE_SEC`.

Проверка сервера ботами: `bun server/test-bots.ts ws://localhost:8790/ws 3` (рейтинговые) или `… 1 duel`. Боты видят только присланный им вид стола; скрипт считает отказы сервера и «утечки» чужих карт.


### Рейтинг (как на FACEIT)

- 10 уровней по Elo: 1 — 100–500, 2 — 501–750, 3 — 751–900, 4 — 901–1050, 5 — 1051–1200, 6 — 1201–1350, 7 — 1351–1530, 8 — 1531–1750, 9 — 1751–2000, 10 — 2001+. Все начинают с 1000 (уровень 4), ниже 100 не опускается.
- За матч: 50 × (итог − ожидание по Elo), округление, от 5 до 45 очков. Равные соперники — ±25.
- Подбор: соперник в пределах ±100 Elo; каждые 5 с ожидания окно шире на 25, максимум ±350. Пара — ближайшие по рейтингу, и разница должна устраивать обоих. Настройки сервера: `MM_BASE`, `MM_STEP`, `MM_MAX`.
- Экран «Рейтинг» в меню: уровень, Elo, место в сезоне, полоса до следующего уровня, друзья и недавние соперники, последние 15 матчей (±Elo, соперник, карта), таблица уровней, призы и топ сезона.

### Призы сезона (скины CS2 за топ-10)

Файл `server/prizes.json` (пример — `server/prizes.example.json`, путь можно сменить переменной `PRIZES`). Сервер перечитывает его при изменении — перезапуск не нужен. Без файла раздел призов не показывается.

```json
{ "ends": "2026-12-31", "minGames": 20,
  "prizes": [ { "place": 1, "skin": "AK-47 | Redline", "wear": "Field-Tested", "rarity": "classified", "image": "https://…" }, … ] }
```

- В рейтинге — блок «Призы сезона»: карточки 1–10 мест с цветом редкости (`consumer`, `industrial`, `milspec`, `restricted`, `classified`, `covert`, `contraband`, `knife`), сколько дней до конца сезона и где сейчас игрок («Вы на 4 месте — в призовой зоне», «До призовой зоны: 37 Elo», «Сыграйте ещё 6 матчей»). В таблице лидеров у призовых мест — название скина.
- В зачёт идут только игроки, сыгравшие не меньше `minGames` рейтинговых матчей за сезон: места раздаются по порядку рейтинга среди них.
- `bun server/server.ts --new-season "Сезон 2"` перед сбросом записывает победителей в таблицу `season_results` (сезон, место, id игрока в Telegram, имя, рейтинг, приз) и печатает список — по нему и выдаются скины.

## Обучение, задания, карточка результата

Обучающий матч (≈26 шагов) объясняет: деньги (доход, перенос до $3000, награды за убийства по классу, энтри, бонус за отставание, закладку и разминирование), как читать карту (цена, атака — жёлтый овал, здоровье — сердце, класс), «кто кого» и свойства бойцов, бомбу, гранаты, снаряжение, бай-меню, силу героя, засады, ветеранов, трофеи, клатч и фирменные карты агентов.

- **Обучение** — плитка в меню (подсвечена, пока не пройдено): пошаговый матч Phoenix против SWAT-новичка на Dust II с заданной рукой. На каждом шаге экран затемнён и заблокирован — нажать можно только нужное (оно подсвечено золотым кольцом с анимацией «дыхания»), остальное не реагирует. Шаги: приветствие → замена карт → добор → деньги → выставить Tec-9 (перетащить или нажать) → «Рывок» против обороны → конец хода → атака бойцом → заложить C4 рядом с бойцом → конец хода → сила героя → удар героем → дальше свободная игра. Пояснения листаются кнопкой «Далее», невозможные шаги (например, бойца уже убили) пропускаются, обучение можно пропустить. Шаги — `TUT_STEPS` в `src/hs/ui.ts`.
- **Задания дня** — три задания, одинаковые у всех (выбираются по дате): выиграть игры, заложить или обезвредить бомбу, бросить флешки, сделать хедшоты, сыграть клатч, победить за конкретного агента, выиграть онлайн и т. д. Засчитываются игры с ботом и онлайн, за каждое — очки; считается серия дней, когда сделаны все три. Хранятся в CloudStorage Telegram. Список — `src/quests.ts`.
- **Поделиться** — на экране итога: картинка 1080×1080 (кадр карты, агент, исход, рейтинг). На телефонах — системное меню «Поделиться» с картинкой; если его нет — картинка открывается поверх игры (долгое нажатие — сохранить) и кнопка отправить текст в Telegram.

## Аналитика (анонимная)

События собирает сам сервер онлайна, в ту же базу SQLite (`server/analytics.ts`). Вместо игрока — случайный номер устройства; имени, Telegram-ID и IP-адресов в базе нет, события старше 120 дней удаляются. Игрок может выключить отправку в настройках (шестерёнка в меню).

- **Куда шлёт игра:** адрес берётся из адреса онлайна: `wss://домен/clutch-ws/ws` → `https://домен/clutch-ws/ws/e` (тот же `location` в nginx, ничего настраивать не нужно). Можно задать явно: `window.CLUTCH_ANALYTICS='https://…/e'`. Нет сервера — аналитика выключена.
- **Отчёт:** `https://домен/clutch-ws/ws/stats?key=ПАРОЛЬ` (пароль — переменная `STATS_KEY` у сервера; `&days=7` — другой период; ссылка «CSV» — выгрузка событий за 30 дней). На странице: устройства, новые, игры с ботом и онлайн по дням; воронка (открыли → обучение → игра с ботом → онлайн → очередь → нашли соперника → доиграли); обучение по шагам — на каком шаге уходят и где жмут «Пропустить»; возвраты на 1/3/7/14/30-й день; винрейт по сложности бота, стороне и агенту; чем заканчиваются партии; медиана поиска соперника; медиана загрузки; соцфункции (друзья, вызовы, реванш); платформы; ошибки JavaScript у игроков.
- **События:** `app_open` (платформа, экран, время загрузки), `tut_start`/`tut_step`/`tut_skip`/`tut_done`, `hs_start`/`hs_game`/`hs_end`, `online_open`, `rating_open`, `online_queue`, `online_found` (ожидание), `online_end` (сторона, агенты, карта, длина, ±Elo), `friend_add`, `invite_send`, `invite_answer`, `rematch`, `pv_more`, `js_error`.

## Проверки (CI)

На каждый push в `main` GitHub Actions (`.github/workflows/ci.yml`) запускает три задачи:
- **Типы и симуляция** — `tsc`, сборка сервера, 100 партий бот против бота, однофайловая сборка.
- **Онлайн** — `scripts/ci-online.sh`: сервер на временной базе, два бота играют рейтинговую игру и дуэль (без «утечек» чужих карт), затем `tests/online-social.ts` проверяет друзей, вызов, отказ, «занят», реванш и недавних соперников.
- **Браузер** — `scripts/check-build.sh` + `tests/e2e.cjs` (Playwright + Chromium): обучение проходится до конца, партия с ботом доигрывается до экрана MVP, без ошибок JavaScript.

Локально то же самое: `bash scripts/ci-online.sh`; `bash scripts/check-build.sh && python3 -m http.server 5183 -d .check` и в другом окне `node tests/e2e.cjs`.

## Загрузка

Пока скрипт игры загружается и запускается, сразу видна заставка (она прямо в `index.html`). Картинки грузятся по мере показа, голоса и выстрелы — к началу партии. В однофайловой сборке голоса и выстрелы лежат JSON-блоками в конце файла и разбираются только при первом обращении. Шрифты — только Onest и Oswald.

## Картинки

Картинки есть у всех карт и лежат в проекте: `public/img/<id карты>.webp` (256×192, ~500 КБ всего), внешние серверы не нужны.

- Ящик — штабель ящиков на миде Dust II (кадр из игры, Counter-Strike Wiki).
- Дверь — модель `models/props/de_nuke/hr_nuke/metal_door_001` из pak01 CS2, отрендерена с цветом оранжевых дверей Nuke (`rendercolor 223 149 32` из `maps/de_nuke.vpk`). Исходники — `assets/cs2/metal_door_001/`: `metal_door_001.glb` (модель с запечённой оранжевой текстурой, normal и AO внутри), `metal_door_001_color_orange.png` (цветная текстура 2048×1024), исходные `_color` (белая база под тонировку), `_tintmask`, `_normal`, `_ao`.

- Тактики — официальные наклейки CS: Wallbang, Roosty Boosty, T Rush, Clutchman, Ninja Defuse, Full Buy.

- Портреты бойцов с оружием (агенты CS2 держат стандартные стволы, сгенерированы по референсам): `public/img/u_<t|ct>_<id>.webp`, 384×512. Нейтральное оружие берёт портрет стороны владельца. Список собирает `scripts/art-index.mjs` (запускается перед dev/build и в `standalone.sh`) — новую картинку достаточно положить в папку.
- Оформление в стиле CS2: главное меню — `src/menu.css`, всё остальное (кнопки, окна, выбор агента, рамки карт, стол) — `src/theme.css`, подключается последним поверх старого «золотого» скина.
- Главное меню (`src/menu.css`) в стиле CS2. Ключевой арт меню — `public/img/ui_menu_key.webp` (вертикальный, 1080×1440); пока его нет, по краям стоят портреты бойцов T и CT.

- Силуэты оружия для килфида и значков классов: `public/img/sil_<id>.webp` — белые маски, делаются из картинок оружия командой `python3 scripts/make-sil.py`.

## Оформление боя

- **Килфид как в CS2** справа сверху: «стрелок → силуэт оружия → жертва», значки хедшота и прострела брони; свои убийства в красной рамке.
- **Выстрелы**: вспышка у ствола, трассер, искры, всплывающий урон; хедшот — красное кольцо, значок и звонкий «дзынь».
- **Состояния бойцов**: ослеплён — белая засветка с волнами, горит — языки пламени, броня — щит с числом, ветеран — золотая звезда, класс оружия — силуэт под портретом.
- **Рука веером**: на компьютере карта под курсором поднимается и увеличивается; сыгранное действие летит из руки к цели.
- **Деньги** зелёными цифрами как в бай-меню, прибавка и трата «бегут».
- **Экран MVP** после партии: агент победителя, лучший боец (убийства и урон).
- Проверка оформления без рук: `#autoplay` в адресе — за игрока ходит бот; `#fxtest` открывает отладочные хуки.

Фон игрового поля и превью карт — кадры локаций из игры (Dust II, Inferno, Mirage, Nuke, Ancient, Anubis, Cache): `public/img/map_<id>.webp`. Путь задаёт функция `img()` в начале `src/game/cards.ts`; чтобы заменить картинку, положите файл с тем же именем. Однофайловая сборка (`scripts/standalone.sh`) встраивает картинки прямо в HTML.

```
src/hs/cards.ts     карты, классы и «кто кого», силы героев, колоды, бай-меню

src/online/         протокол (поворот стола, скрытие карт) и подключение к серверу
server/server.ts    сервер онлайна (Bun + SQLite), server/analytics.ts — аналитика, server/test-bots.ts — проверка двумя ботами
tests/              online-social.ts (друзья, вызов, реванш), e2e.cjs (обучение и партия в браузере)
.github/workflows/  CI: типы, симуляция, онлайн, браузер
```

> Названия и изображения из CS2 принадлежат Valve. Для бесплатного фан-проекта это обычная практика; перед монетизацией проверьте правила Valve.

## Радиокоманды (голос)

Фразы рации («Fire in the hole!», «Bomb has been planted», «Terrorists win» и др.) играют из файлов в `public/snd/vo/`.
Если файла нет, звучит щелчок рации, а фраза появляется текстом в радио-чате.

- Общий голос: `public/snd/vo/<ключ>.mp3`. Варианты одной фразы: `<ключ>2.mp3`, `<ключ>3.mp3`.
- Голос конкретного агента: `public/snd/vo/<id агента>/<ключ>.mp3`, например `t_phoenix/fireinhole.mp3`.
- Ключи: `go`, `fireinhole`, `flash`, `smoke`, `molotov`, `enemydown`, `enemyspotted`, `niceshot`, `takingfire`, `needbackup`, `clutch`, `bombpl`, `bombdef`, `ctwin`, `terwin`.
- Список файлов `index.json` собирается сам перед `npm run dev` и `npm run build` (`node scripts/vo-index.mjs`).
- Фразы извлечены из pak01 CS2 скриптом `python3 scripts/cs2-vo-extract.py "<…>/game/csgo"` (нужен ffmpeg). После обновления игры его можно запустить заново.

Откуда взяты фразы (по 3 варианта на ключ, у агентов — свой голос):

| Агент | Папка в CS2 | Особенности |
|---|---|---|
| SAS `ct_sas`, SEAL `ct_seal`, Phoenix `t_phoenix`, Elite Crew `t_elite`, Balkan `t_balkan` | `sas`, `seal`, `phoenix`, `leet`, `balkan` | классическое радио: `radio.letsgo`, `radio.enemyspotted`, `radio.takingfire`, `radio.needbackup`, `enemydown`, `niceshot`, `lastmanstanding` |
| SWAT `ct_swat`, FBI `ct_fbi`, Professional `t_pro` | `swat`, `fbihrt`, `professional` | реплики ботов: `radiobotgo`, `radiobotkill`, `radiobottarget`, `radiobotunderfire`, `radiobotniceshot`, `coverme`; фразы «последний» у них нет — `clutch` берётся из общего голоса |
| GIGN `ct_gign`, Партизан `t_guerrilla` | `gendarmerie_male`, `jungle_male` | новые голоса: `round_start`, `throwing_*`, `i_killed_enemy`, `sees_enemy`, `compliment`, `takingfire`, `request_backup`, `last_unit_alive` |

Гранаты у всех — `ct_/t_grenade`, `_flashbang`, `_smoke`, `_molotov` (или `throwing_*`). Общий голос (`public/snd/vo/<ключ>.mp3`) — SAS, Phoenix и SEAL по очереди. `bombpl`, `bombdef`, `ctwin`, `terwin` — диктор `announcer/cs2_classic` (только общий).

Голоса CS2 принадлежат Valve. Перед публичным запуском с призами стоит заменить их своими записями.
